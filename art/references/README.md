# Art References

Materiais usados como **referência visual e técnica** durante a criação de **A Escória**.

Esta pasta não é fonte de assets do jogo. Ela existe para orientar decisões de estilo, proporção, composição, UI, animação, cenários e equipamentos.

## Estrutura

```text
references/
├── visual_style/
├── characters/
├── equipment/
├── animation/
├── ui/
├── environments/
└── research/
```

## O que pode entrar aqui

- imagens de referência;
- screenshots de jogos;
- estudos próprios;
- moodboards;
- exemplos de composição;
- referências de animação;
- referências de UI/UX;
- estudos comparativos.

## O que não deve entrar aqui

- assets finais do jogo;
- arquivos `.kra` de produção;
- exports usados pelo Godot;
- versões aprovadas que já pertencem ao pipeline oficial.

## Referências do projeto

Entre as referências conceituais de **A Escória** estão jogos e linguagens visuais usadas apenas como orientação, não como material para cópia literal.

A referência serve para responder perguntas como:

- Como a silhueta funciona?
- Como o equipamento é lido?
- Como uma animação comunica uma ação?
- Como uma zona ganha identidade?
- Como a interface organiza informação?

A direção oficial sempre prevalece sobre uma referência externa.

## Organização recomendada

Use nomes que expliquem o motivo da referência:

```text
isometric_character_silhouette.png
armor_readability_reference.png
idle_animation_reference.png
resource_node_ui_reference.png
```

Quando possível, registre a origem da referência no nome ou em um pequeno `.md` ao lado do arquivo.
