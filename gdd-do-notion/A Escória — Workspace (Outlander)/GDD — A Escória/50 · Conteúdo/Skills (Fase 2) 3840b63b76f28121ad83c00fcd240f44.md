# Skills (Fase 2)

Cada arma tem 3 slots (Q/W/E); armaduras adicionam skills. Texto **escala por tier** (A6).

## Slots

- **Q/W** — escolha entre opções; **E** — fixo; **Auto-attack** — cd ~1-1.5s.

## Template

```
id: skill_<linha>_<slot>_<nome>
slot: Q | W | E
efeito_mecanico: ""
cooldown_ms: 0
texto_log_por_tier:
  t1: "seu braço soube o ângulo"
  t3: "a lâmina puxou primeiro"
  t6: "vocês dois escolheram o mesmo alvo"
```

## Regra

A mesma skill **não muda de efeito** necessariamente, mas **muda de texto** — mais ambígua sobre quem age.

- [ ]  Log em T1/T3 (PoC) e esboço T6.
- [ ]  Skills das armaduras.
