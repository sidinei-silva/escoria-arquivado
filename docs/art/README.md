# Art Documentation

Documentação oficial da direção de arte de **A Escória**.

Esta pasta contém os guias, regras e especificações que definem como a arte do jogo deve ser criada e mantida consistente durante a produção.

## Estrutura

- `00_direcao_de_arte/` — identidade visual, princípios e regras gerais.
- `01_personagem/` — proporções, corpo base, silhueta e construção.
- `02_equipamentos/` — equipamentos, slots, modularidade e encaixes.
- `03_animacao/` — poses, ciclos, spritesheets e regras de animação.
- `04_ui/` — botões, painéis, modais, HUD e componentes.
- `05_telas/` — wireframes e especificações das telas do jogo.
- `06_cenarios/` — cenários, zonas, tiles e assets reutilizáveis.
- `07_vfx/` — impactos, efeitos, coleta, Têmpera e recompensas.
- `08_producao/` — exportação, nomenclatura, escala e workflow.

## Regra principal

Os documentos desta pasta definem **como a arte deve ser produzida**. Eles não substituem os arquivos fonte nem os assets usados pelo jogo.

Quando uma decisão artística mudar:

1. Atualize o guia correspondente.
2. Verifique se os assets afetados continuam compatíveis.
3. Atualize os arquivos fonte em `art/source/`.
4. Gere novamente os arquivos de `art/exports/` quando necessário.

## Fonte de verdade

O **Manual de Direção de Arte — A Escória** é a referência principal para a linguagem visual. Guias específicos detalham sua aplicação em cada categoria.
