# sistemas/

**A referência: qual é a regra, e o número.**

Um arquivo por sistema. Sistema é algo com regras próprias que outros sistemas
consultam — não é funcionalidade nem tela.

O prefixo do ID espelha o arquivo: `coleta.md` → `R-COL-*`.

## O teste que separa regra de prosa

> *"O Guia parou perto do T8 por medo"* → prosa. Não testável, e não deve ser.
> *"Têmpera reseta na troca"* → regra. Numerada, testável.

**Regra sem teste é decoração.** Se não vale um teste, não vale um ID.

## O falso terceiro tipo

"Nome entre 3 e 20 caracteres" não é regra de jogo — é validação de software.
Não ganha ID, não entra aqui. Vive na spec ou na issue.

A pergunta que decide: *se eu trocasse Go por Rust e web por mobile, isso
continuaria valendo?* Sim → regra. Não → encanamento.

## Quando um arquivo nasce

Quando um fluxo cita uma regra que ainda não existe. Nunca por antecipação.

É aqui que a **migração preguiçosa** do Notion acontece: desce só o sistema da
fatia atual, não o resto.

## Tamanho

Curto. Navegação, prosa em parágrafos, regras em lista. Passou de duas telas,
provavelmente são dois sistemas.

## Numeração

Sempre cresce, nunca é reaproveitada. Regra removida deixa o número vago.
