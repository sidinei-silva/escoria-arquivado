# Glossário

Dois registros convivem: **diegético** (como os personagens dizem) e **técnico** (lore/design).

## Universo & Lore

| Termo | Definição |
| --- | --- |
| **O Silêncio** | Evento que cortou a devoção de todos os panteões. Manipulação em 3 camadas. |
| **A Enumeração** | 1ª camada: catalogar os deuses os tornou finitos. |
| **O Pacto de Continência** | 2ª camada: os deuses cortaram a devoção voluntariamente. |
| **A Escória** | O **mapa inteiro do jogo** — universo paralelo entre os universos dos panteões. Gíria de forja. |
| **A Margem** | Borda neutra de A Escória; onde os recém-caídos chegam. |
| **A Margem Calada** | A **ilha tutorial** — um caco recente da Margem. |
| **As Carcaças** | Regiões interiores; cada uma = cadáver de um mundo-panteão (Pálida, Solar, Reverenciada, Trovejada, Tropical). |
| **As Encruzilhadas** | Rede neutra entre Carcaças; futuras portas para dungeons-panteão. |
| **A Forja Calada** | Cidade neutra de A Escória (pós-PoC). |
| **A Fome** | Profundezas/endgame; onde os Mitos sem Pacto mais fortes vivem. |
| **O Interstício** | Mesmo lugar, no vocabulário acadêmico. |
| **O Incrédulo** | Antagonista. Nascido da saturação. Quer a Calcificação da Realidade. |
| **Calcificação da Realidade** | Objetivo do Incrédulo: mundo previsível, sem mito nem milagre. |
| **Mitos sem Pacto** | Criaturas que perderam contenção. Os "monstros". |
| **Portador** | Quem empunha uma arma-deus. |
| **Pessoa-mito** | Resultado do T8: fusão irreversível deus+portador. |
| **Ruído divino difuso** | Eco coletivo de deuses de um domínio, sentido em T1–T3. |

## Sistema & Economia

| Termo | Definição |
| --- | --- |
| **Fama** | Moeda de progressão d'**A Litania** (diegese: "lembrança"). |
| **Lastro** | Moeda corrente. Resíduo neutro de mito coagulado. Separado da Fama. |
| **Tier (T1–T8)** | Nível do *item*, não do personagem. PoC: T1–T3. |
| **A Litania** *(ex-Destiny Board)* | Árvore de progressão por **uso/lembrança**. Recitação que desperta o deus; lista que o cataloga (Enumeração). T4 cristaliza deuses distintos. |
| **Loadout** | Peças equipadas = identidade mecânica atual. |
| **Cristalização (T4)** | Um deus específico emerge e o jogador o deixa entrar. |
| **Reciprocidade irreversível (T8)** | Fusão final; gatilho do metagame de rebirth. |

## Personagens

| Termo | Definição |
| --- | --- |
| **O Catador** | O protagonista. Ex-coletor de sucata, puxado para a Escória. |
| **O Guia** | Recepcionista da ilha. Ex-portador que parou perto do T8. |

> Nomes próprios de deuses, zonas, facções e itens serão fixados na **Fase 2**.
