## Stack (PoC)

| Camada | Tecnologia |
| --- | --- |
| Frontend | React + Vite + TypeScript + Zustand |
| Backend | Go |
| Queries | sqlc |
| Migrations | golang-migrate |
| Banco | SQLite ([modernc.org/sqlite](http://modernc.org/sqlite)) |
| Conteúdo | JSON versionado no Git |
| Comunicação | HTTP REST (polling) |

## Princípios relevantes ao design

- **Conteúdo é JSON, não código:** nomes/descrições/lore vivem em `data/`. **A camada criativa da Fase 2 são esses JSONs.**
- **Banco só guarda estado dinâmico.**
