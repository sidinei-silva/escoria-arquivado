# Escopo da PoC

Cânone fixo 8. A PoC cobre o fluxo de tutorial na **Margem Calada**, a ilha inicial, sem outros jogadores.

## Objetivo único

> Validar o core loop: *zona define ação → ação gera recurso/fama → fama progride A Litania → progressão desbloqueia novo conteúdo.*
>

## Sistemas na PoC

| Sistema | Na PoC? |
| --- | --- |
| Coleta por zona | Sim |
| Crafting e refino | Sim |
| Auto-battler + fila | Sim |
| A Litania (T1–T3) | Sim |
| Fama por uso (Catador + arma) | Sim |
| Lastro (Passo 5) | Sim |
| Têmpera (por arma) | Sim |
| Inventário (slots + peso) | Sim |
| Multiplayer, PvP e gank | Não (pós-PoC) |
| T4+ / ordenação | Estrutura preparada, não jogável |

## Critério de "PoC validada"

1. Player completa os 8 passos sem travar (chega de mãos vazias; recebe T1 no Passo 2; forja a primeira T2 no Passo 5).
2. O loop fecha.
3. Narrativa mínima (Prévio + falas-âncora) presente.
4. Lastro e Fama percebidos como **coisas diferentes**.
